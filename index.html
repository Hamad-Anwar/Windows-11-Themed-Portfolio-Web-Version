Mac theme portfolio by Hamad Anwar

A Mac theme portfolio is a personal site that looks and works like a Mac desktop. This one is built in Flutter by Hamad Anwar (also known as Hammad Anwar). Open it in the browser and you get a menu bar, a dock, draggable windows, photos, projects, and a terminal. The same site also includes a Windows 11 theme portfolio.

What is this Mac theme portfolio?

This macOS themed portfolio recreates a Mac desktop on the web. The menu bar sits at the top. Desktop icons open About, projects, photos, a licence window, and settings. The dock magnifies as you move across it. Windows drag, resize, and go full screen. Photos can be cropped and reordered. A terminal accepts commands. You can change the wallpaper.

It is a Flutter Mac portfolio: one Flutter codebase draws the desktop, so the same interface runs in the browser on a phone, a tablet, or a computer.

Does this site include a Windows 11 theme portfolio?

Yes. Switch from the Mac desktop to a Windows 11 themed portfolio on the same page. That desktop has a taskbar, a Start menu, a calendar, a control center, window snapping, and draggable windows. Both themes are part of Hamad Anwar’s Flutter portfolio at https://hamad-anwar.vercel.app/.
